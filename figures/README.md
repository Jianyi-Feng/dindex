# Figure rendering

The five scripts here reproduce every published figure and their per-figure source data.
They write into the repository-level `outputs/` folder (ignored by git).

## Render order (important)

```bash
cd figures
python make_figures.py                 # main Figs. 1-5, Extended Data Figs 1,2,3,5 + source data
python make_extended_data_fig4.py      # Extended Data Fig 4 -- MUST run after make_figures.py
python make_supplementary_fig3_components.py      # Supplementary Fig. 3 (projected order abundances)
python make_supplementary_figs4_5_pnps_network.py  # Supplementary Figs 4-5 (pN/pS + network)
python build_supplementary_figures.py  # assembles the Supplementary Figures DOCX
```

`make_extended_data_fig4.py` re-uses panels written by `make_figures.py`, so the order matters.

## Environment

The published PDFs were rendered with **matplotlib 3.11.2** on Linux. `requirements.txt` pins that
version: any 3.9+ release renders, but tick padding, constrained-layout spacing and font metrics can
shift between minor versions, so pin it if the layout has to match the manuscript exactly.

## Fonts (Arial)

The scripts request Arial and verify nothing else is substituted. matplotlib cannot see Arial
unless it is installed on the render host; without it the figures fall back to DejaVu Sans and come
out in the wrong typeface.

```bash
# easiest, if you have sudo + network
sudo apt-get install ttf-mscorefonts-installer

# or copy Arial.ttf (arial.ttf, arialbd.ttf, ariali.ttf, arialbi.ttf) into ~/.fonts, then
fc-cache -f -v ~/.fonts
rm -rf "$(python -c 'import matplotlib;print(matplotlib.get_cachedir())')"   # matplotlib caches separately
```

Verify before rendering — `check_render_env.py` below does the same check as the original render gate:

```bash
python figures/check_render_env.py          # dependency + Arial check
python figures/check_render_env.py --strict # exit non-zero if Arial is missing
```

Arial is a licensed Monotype/Microsoft font, so the font files are **not** included in this
repository; install them with the commands above (the same end use as `ttf-mscorefonts-installer`).

## Not regenerated by any script

Supplementary Figs 1 and 2 are raster exports (iTOL phylogeny and a gene heatmap) produced outside
this pipeline; the seed copies in `outputs/supplementary/` are carried through unchanged.
